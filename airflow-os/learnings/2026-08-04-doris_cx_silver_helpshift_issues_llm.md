> 이 파일은 공개 레포에 올라간다. 스키마·실측 수치·업무 협의 내용은 운영 레포 `designs/`의 설계도에 있다.

## 무엇을

소스 테이블의 미처리 행을 커서로 집어, 행별로 LLM을 세 번(번역→요약→분류) 부르고 결과를 upsert하는
DAG를 신규로 만들었다. 설계→구현→테스트→리뷰를 **4라운드** 돌았고, 리뷰가 매 라운드 결함을 찾았다.

## 왜 (결정과 트레이드오프)

- **LLM 단계를 한 태스크에 몰지 않고 셋으로 나눴다.** UI 그리드에서 실패 지점이 바로 보이고,
  재시도가 앞 단계를 다시 결제하지 않는다. 대가는 매핑 태스크 수 3배 + 중간 산출물이 XCom을 통과하는 것.
- **고정 cron 대신 상류 자산 트리거.** 처음엔 새벽 cron이었는데, 상류 적재가 오전이라 매 런이
  **하루 묵은 데이터**를 보게 돼 있었다. 시각을 맞추는 대신 상류 완료 신호를 받도록 바꿨다.
- **재분류 판별에 같은 성격의 두 시각을 쓴다.** "소스 갱신 시각 vs 우리 처리 시각"으로 비교하면
  상류 수집 컷과 우리 런 시작 사이에 갱신된 행이 조건을 영영 만족하지 못한다. 소스 시각을 타깃에
  복사해 두고 그것과 견주도록 컬럼을 하나 늘렸다.
- **Connection은 접속 정보만, 단계별로 다른 값은 Variable.** 처음엔 단계마다 Connection을 뒀는데
  엔드포인트·키가 전부 같아 **같은 비밀키를 세 곳에 복사**하는 꼴이었다.
- 프레임워크 제공 데코레이터로 다시 짜는 안(v2)을 설계서로 남기고 이번 사이클엔 보류했다.

## 발견 / 배운 점

1. **leaf 태스크에 `all_done`을 걸면 실패가 초록이 된다.** DagRun 상태는 leaf로 결정되므로,
   행별 실패를 허용하려고 `all_done`을 쓰면 상류 실패·전량 실패까지 success로 끝난다.
   leaf가 스스로 "처리 대상이 있었는데 0행 적재" 같은 판정을 해야 한다. **실측으로 재현 확인.**
2. **매핑 출력을 `list()`로 순회하면 인덱스가 밀린다.** 존재하는 XCom만 모이므로 skip된 자리가
   사라지고, 입력과 zip하면 **다른 행에 결과가 붙는다.** 위치로 행을 잇지 말 것.
   꼭 필요하면 `map_indexes`를 명시해 당긴다 — 빈 자리가 `None`으로 남아 정렬이 보존된다.
3. **매핑 단계 사이엔 `trigger_rule="all_done"`이 필수.** 기본값이면 인스턴스 하나만 skip돼도
   하류 단계가 **통째로** skip된다.
4. **공용 XCom 백엔드가 payload 전문을 INFO 로그로 찍고 있었다.** 임시 디버그 잔재였는데,
   원문을 XCom으로 나르는 DAG를 만들면서 처음 문제가 됐다. 공용 인프라가 조용히 남기는 것을 확인할 것.
5. **설계 단계에서 "이걸 이미 해주는 기능이 있나"를 조사하지 않았다.** 손으로 짠 재시도 루프·
   구조화 출력이 프레임워크 provider에 이미 있었고, 사용자가 찾아내 4라운드째에 재검토했다.
6. 서브에이전트는 **세션 루트의 `.claude/agents`만** 로드된다(스킬은 하위 폴더도 잡힌다).
   OS 폴더를 루트로 열지 않으면 워커 호출이 실패하고, 컨텍스트 상대경로도 어긋난다.

## 다음에 재사용할 것

- **행별 LLM DAG 골격**: 단계 분리 → 각 단계가 키를 담은 dict를 **통째로** 넘김(위치 의존 금지) →
  단계 사이 `all_done` → leaf가 런의 성패를 판정 → 0행이면 자산 이벤트를 발행하지 않음.
- **재시도 예산을 계산해 문서에 남긴다.** `최대 시도 × 호출 타임아웃 + 대기 합`이 그 태스크의
  `execution_timeout` 안에 들어오는지. SDK 자체 재시도를 켜두면 우리 루프와 **곱해진다**.
- **설계 착수 전 조사 항목**: "이 일을 이미 해주는 provider·데코레이터가 있는가".
  없다고 단정하지 말고 constraint 파일과 provider 소스를 실제로 확인한다.
- **회사 자산이 섞이는 산출물은 공개 레포에 두지 않는다.** 설계도는 gitignore로 못박고 운영 레포에 둔다.
