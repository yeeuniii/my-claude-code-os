# lint — OS 작성 규칙 린터

`.claude/`의 스킬·서브에이전트·컨텍스트가 **작성 규칙**을 지키는지 점검한다. 리포트만, 코드는 고치지 않는다.

## 기준
CLAUDE.md의 `## 작성 규칙`을 먼저 Read해 그걸 기준으로 삼는다 — 규칙이 바뀌면 이 스킬은 손대지 않아도 따라간다.

## 대상
- `.claude/skills/*/SKILL.md`
- `.claude/agents/*.md`
- `.claude/context/` (하위 디렉토리 포함)

## 점검 항목
CLAUDE.md 작성 규칙의 **각 항목**에 대해 위반을 찾는다. 여기 목록을 다시 적지 않는다 — 규칙이
늘거나 바뀌면 이 스킬이 자동으로 따라가야 한다.

판단이 갈리는 지점만 적어둔다:
- 오케스트레이터가 **자기 워커·단계**를 이름으로 부르는 것은 정당하다(위반 아님).
- description이 불필요하게 길면(대략 200자+) 플래그.

## 출력
- 위반을 `[항목] 파일:라인 — 무엇이 / 어떻게 고칠지`로 항목별 정리.
- 위반 없으면 **"통과"** 명시.

## 수정
- 리포트 후 사람이 승인하면 **수정을 적용한다**(사람은 승인만, 편집은 AI).
- 자동으로 먼저 고치지 않는다 — 리포트가 먼저.

## 원칙
- 기준은 CLAUDE.md 작성 규칙 하나 — 판단이 갈리면 그걸 따른다.
